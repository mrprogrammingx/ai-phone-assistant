# Call log

The trial includes **60 minutes**. Every call counts, including browser test calls. These figures are documented by Suisse Line and not yet confirmed in an account.

- **Target:** 34 minutes of test calls.
- **Floor:** 20 minutes remaining.
- **Rule: stop testing at 20 minutes remaining**, and keep those minutes for the interview.

Take the duration from the dashboard after each call, not from the planned figure.

## Before each call

- [ ] The base URL still works
- [ ] The tunnel is running
- [ ] The Mac is awake
- [ ] The demo database is seeded
